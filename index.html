Расценки (без вычета НДФЛ)

Вид работЦена, ₽Ед.

Цена 0 значит «ещё не задана» — такая работа считается, но денег не добавляет. Впиши цену, когда узнаешь. Изменение цены не пересчитывает уже внесённые записи.

Обновление расценок по ссылке

Опубликуй файл расценок в интернете один раз — и все, у кого есть ссылка на приложение, будут получать новые цены сами.

Обновления ещё не проверялись.

Как это работает: правишь цены → «Скачать файл расценок» → заливаешь файл на тот же адрес. У остальных цены обновятся при следующем открытии. Записи о работах при этом не затрагиваются.

Важно про ссылку: подходит прямая ссылка на файл (GitHub Pages, raw-ссылка, свой сайт). Для Google Диска нужна «Опубликовать в интернете», а не «Поделиться» — иначе придёт страница вместо файла. Для Яндекс.Диска — «Опубликовать» и прямая ссылка на скачивание.

Данные и резервная копия

Записи хранятся только в этом браузере — на сервер ничего не уходит, и на другом устройстве их не будет. Чтобы не потерять данные при чистке кэша или перенести на телефон/компьютер — сохраняй файл копии.
